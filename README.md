# 🍔 Food Ordering System in Java

## 📌 Overview

This project was developed as part of a Java programming course during my 2nd semester at East West University.

The Food Ordering System is a console-based application that allows customers to register, log in, browse food items, place orders, and track order status. Administrators can manage food items and update order statuses.

The project demonstrates the practical application of Object-Oriented Programming (OOP), file handling, interfaces, collections, and system design in Java.

---

## ✨ Features

### Customer Features

* User registration
* Secure login system
* View food menu
* Place food orders
* View personal order history

### Admin Features

* Admin authentication
* Add food items
* Remove food items
* View all orders
* Update order status

### System Features

* File-based data persistence
* Order tracking
* Menu management
* Customer management
* Automatic data loading and saving

## 💾 File Handling

The system stores data using text files:

* users.txt
* foodmenu.txt
* orders.txt

Data is automatically loaded when the program starts and saved when it exits.

## 🔄 System Workflow

1. User selects Admin Login, Customer Login, or Registration.
2. Customer logs in and browses available food items.
3. Customer places an order.
4. Order information is stored and managed by the system.
5. Admin can view and update order status.
6. Data is saved to files for future use.
